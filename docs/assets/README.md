# README screenshots

Captured from the current local production build of Hairroom on 2026-10-15.

- `studio.jpg`, `editor.jpg`, and `mobile.jpg` use only the project's fictional AI-generated adult demonstration model. No personal photos are included. See [demo asset provenance](../../public/images/ASSETS.md).
- `home.jpg` shows the live hairstyle gallery. Real reference photographs are served by Unsplash; photographer credits and source links are available when opening each photograph in the app. The catalogue and attribution URLs live in [hair-looks.js](../../src/lib/hair-looks.js). The gallery also contains explicitly labelled AI examples.
- `icon.svg` is the application's existing Hairroom favicon.

Screenshots illustrate the interface. They do not establish hairstyle transfer quality or actual haircut results. The optional OpenAI try-on and local GPU fill service were not used in these captures.
